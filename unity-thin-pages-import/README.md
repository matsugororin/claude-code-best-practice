# ユニティ層 薄いページ一括投入ツール

Revolution Idle Wiki（Notion・索引DB）へ、ユニティ層の全要素を「薄いページ」として
一括投入するためのスクリプトとシードデータ。仕様は本ディレクトリ外の作業指示書に準拠。

## ファイル

| ファイル | 役割 |
|---|---|
| `notion_bulk_import.py` | 投入スクリプト（`requests` に依存） |
| `elements.json` | 投入対象のシードデータ（初期25件） |
| `failed.json` | 実行後に生成。失敗した要素（オブジェクト全体）を保存。`--retry-failed` で再投入 |
| `imported.log` | 実行後に生成。投入済み要素名・ページID・時刻を追記 |

## 依存

```bash
pip install requests
```

## 実行手順

```bash
export NOTION_TOKEN='ntn_xxxxx'
cd unity-thin-pages-import
python3 notion_bulk_import.py --dry-run        # 送信せず投入内容を確認（最初は必ずこれ）
python3 notion_bulk_import.py                  # 本番投入
python3 notion_bulk_import.py --retry-failed   # failed.json の要素だけ再投入
python3 notion_bulk_import.py --file other.json  # 入力JSONを差し替え
```

`--dry-run` はトークン無しでも動作する（プロパティと本文プレビューを表示するのみで
送信・重複チェック・実DB語彙照合をしない）。本番投入・`--retry-failed` は `NOTION_TOKEN` 必須。
dry-run 出力にはページごとに `[properties]`（送信するプロパティJSON）と
`[本文プレビュー]`（見出し+段落として実際にNotion上で見える形）の両方を表示する。

## 安全設計

- **allow-list 検証**: `種別` / `確定度` / `強化対象` / `参照する記録` を許可リストで検証。
  未知の値が1件でもあれば**全件中止**（exit code 1）。Notion の multi_select が
  未知値を勝手にオプション化して語彙を汚染するのを防ぐ。JSON内の `要素名` 重複も検出して中止する。
  - `種別` / `確定度` は静的な `ALLOWED_*` 定数のみで検証する（値の種類が固定のため）。
  - `強化対象` / `参照する記録` は `ALLOWED_*` 定数（ユニティ層追加分＋既存語彙の推測値）に加え、
    `NOTION_TOKEN` があれば `GET /v1/databases/{id}` で取得した**実DBの現在の選択肢**を
    マージして検証する。既存語彙の推測値がDBの実際の表記とズレていても、実DBに存在する
    正しい値なら通過し、本当に未知の値（typo等）だけが弾かれる。トークンが無い場合は
    静的allow-listのみで検証し、その旨を警告表示する（`--dry-run` をトークン無しで
    使える状態は維持）。
- **重複防止**: 実行前に索引DBを全件クエリし、同名 `要素名` があればスキップ。
  タイトルが複数のrich-textラン（スタイル混在等）に分かれていても全ランを連結して
  比較するため、既存ページを別名と誤認しない。再実行しても二重登録されない（冪等）。
- **レート制限**: 1件ごとに 0.34 秒スリープ（Notion ~3 req/sec）。
- `階層` は全件 `ユニティ` 固定でスクリプトが付与（JSONには書かない）。
- `定義` はプロパティではなく本文（heading_2 + paragraph）に流し込む。

## シードデータの状態

初期25件は作業指示書 §7 のシードに、Wiki原文から確認した `定義`（1〜2文、本文に反映）
と `備考` を加えたもの：

- 全件 `確定度 = 要検証`
- `強化対象` / `参照する記録` は空（原文確認後に PATCH で追記する運用）
- `自動売却ゾディアック` の解放条件は原文未確認のため空文字（§0 のルール）
- `定義` が `〔未記載〕` の要素（研磨・磁石・ルーン・特殊鉱物・タロットアップグレード・
  宝石サクリファイス・タロットチャレンジ・アーティファクト）は原文からの定義抽出が未完了
